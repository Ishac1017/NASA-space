# Moonbound V1.9 changelog

- Extended NASA/JPL Table 1 planet model from four to all eight major planets.
- Added dynamically drawn eccentric orbital paths and simultaneous planetary positions in full Solar modal and on Flight.
- Unified flight/planet simulation epoch during transfers, including time acceleration and pausing.
- Added 1×, 10×, 100×, 1000× flight clock controls and ALL 8 / INNER 4 display modes. Fast-forward stops at unanswered alerts.
- Added per-room editable +/- quantities for backup power, electronics spares, science calibration kits and provisions in BUILD.
- Added per-room editable +/- quantities in the Flight cabin service panel, with visible Practice designation and suppression of profile score awards for runs with artificial mid-flight supplies.
- Added over-capacity design readiness checks; changed amounts still contribute to mass and cost.
- Retained the existing missions, flight effects, repairs, profiles, music and artwork from V1.8.
- Added an offline logic regression suite and a new English/Chinese setup guide.
- Browser testing of V1.9 was blocked by testing environment navigation policy; manual verification recommended.
