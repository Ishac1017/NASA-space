# Original Moonbound V1.9 source reference

These files were provided by the user as Yafang's Moonbound V1.9 design source. They are included for traceability and further iterations; **they are not loaded by the React/Vite app**. The full original Moonbound `assets/` directory was not included in the uploaded root files. The playable fusion uses selected user-provided PNG assets from the connected Google Drive App Visual Kit in `public/moonbound`, as well as the original Mission Lab assets in `public/visual-kit` and `public/audio`.

The source game included a cabin logistics system; the playable fusion intentionally does not port that system because the user explicitly requested excluding it. The Mars mission is likewise replaced by Neptune in the playable fusion. Reference code here does not enable Mars or cabin logistics in the fusion game.
